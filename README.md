# Flyrank AI Capstone Project

## Overview
This repository contains the frontend capstone project for the Flyrank AI Frontend Engineer track.

## Getting Started

To set up and run the project locally, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```

For any questions or issues, please refer to the project documentation or contact the maintainer.
